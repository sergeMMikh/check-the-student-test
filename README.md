# check-the-student-test

Простой Python-скрипт для поиска и анализа специальных Unicode-символов в текстовых файлах.

## Возможности

Скрипт обнаруживает следующие символы:

- **Узкий неразрывный пробел**- `U+202F`
- **Длинное тире (em dash)**- `U+2014` (`—`)
- **Неразрывный пробел**- `U+00A0`
- **Стрелка вправо**- `U+2192` (`→`)

Для каждого найденного символа скрипт:
- выводит номер строки;
- показывает саму строку;
- указывает **все позиции** символа в строке (нумерация с 0);
- считает **общее количество вхождений**, а не просто количество строк.
